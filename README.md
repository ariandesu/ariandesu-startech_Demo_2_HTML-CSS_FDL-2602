# StarTech Demo 2 — HTML/CSS E-Commerce Layout (FDL-2602)

StarTech-inspired e-commerce product page built with pure **HTML + CSS** — header, category menu, product hero, specifications table & category grid.

> Assignment: `FDL-2602` — learned and practiced CSS layout, box model & responsive grids here.

## 🌟 Features

* Header bar with logo, search input, offers / account / PC-builder icons
* Category menu — Desktop, Laptop, Component, Monitor, Phone, Camera, TV, AC, Gaming & more
* Product hero — MSI G2412V 23.8" FHD 100Hz IPS monitor with key features
* Specifications table + category tiles (AC, Camera, Drone, Mobile, Watch, SSD, etc.)
* Custom `design.css` — `.box1` cards, hover states, flex layout

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (no frameworks)
* **Assets:** PNG product images + `product.webp` hero
* **Layout:** Tables + flex boxes, Arial system font

## 🚀 Run Locally
